## Food Shop Management System (C++)
A simple console-based **Food Ordering System** developed in **C++**.
This project allows users to order different food items like burgers, pizza, shawarma, and deals, along with a basic payment system.

## Features
* Multiple Burger Options
* Shawarma Ordering System
* Pizza Menu
* Special Deals Packages
* Payment Methods (Cash & Online)
* User Information Input

  
## Technologies Used
* **C++**
* Standard Libraries:
  * iostream
  * iomanip
  * windows.h
